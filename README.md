# Keerthana Tejaswi — Portfolio

A responsive personal developer portfolio built with React, Vite and CSS.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Before publishing

- Replace `YOUR_EMAIL@example.com` in `src/App.jsx` with your professional email address.
- Check the GitHub and LinkedIn profile links.
- Add real repository/demo links for each project.
- Add only certifications and achievements you have actually earned.
- Review all project descriptions so they accurately match your work.

## Create a production build

```bash
npm run build
```

The production files will be generated in the `dist` folder. You can deploy the project using Vercel or Netlify.
